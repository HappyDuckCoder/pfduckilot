
Tài liệu: Tìm hiểu BeautifulSoup và Crawl dữ liệu Web
----------------------------------------------------

1. BeautifulSoup là gì?
------------------------
BeautifulSoup là một thư viện Python giúp trích xuất dữ liệu từ các trang HTML và XML một cách dễ dàng. 
Nó thường được dùng để crawl dữ liệu (thu thập dữ liệu) từ các trang web tĩnh.

Công dụng chính:
- Trích xuất dữ liệu từ HTML
- Tìm kiếm nhanh theo tag, id, class
- Làm sạch nội dung HTML
- Hỗ trợ kết hợp tốt với thư viện requests hoặc urllib

2. Cơ chế hoạt động của BeautifulSoup
--------------------------------------
Cách hoạt động:
1. Gửi yêu cầu đến trang web bằng requests
2. Nhận về mã nguồn HTML của trang
3. Dùng BeautifulSoup để parse HTML thành một cấu trúc cây
4. Dùng các hàm tìm kiếm để lấy ra các phần tử mong muốn (tag, class, id,...)

Khi nào crawl được, khi nào không?

| Trường hợp                          | Có thể crawl | Lý do                                          |
|------------------------------------|--------------|------------------------------------------------|
| Web tĩnh (HTML cố định)            | Có           | Dữ liệu hiển thị trực tiếp trong HTML         |
| Web động (dùng JavaScript)         | Không        | BeautifulSoup không chạy được JavaScript      |
| Web chặn bot (Cloudflare, CAPTCHA) | Không        | Cần xử lý nâng cao (headers, Selenium, v.v.)  |

3. Các cú pháp cơ bản
----------------------

a) Crawl cơ bản – Lấy nội dung HTML
------------------------------------
import requests
from bs4 import BeautifulSoup

url = "http://lamdongcdc.vn/"
res = requests.get(url)
soup = BeautifulSoup(res.content, "html.parser")
print(soup.prettify())

b) Crawl toàn bộ – Lấy toàn bộ các thẻ cụ thể
----------------------------------------------
all_links = soup.find_all('a')
for link in all_links:
    print(link.get('href'), link.text)

c) Crawl theo class
---------------------
titles = soup.find_all(class_='name')
for item in titles:
    print(item.text)

# hoặc dùng CSS selector
titles = soup.select('.name a')

d) Crawl theo tag
-------------------
title = soup.find('h2')
print(title.text)

e) Crawl theo ID bất kỳ
-------------------------
main_content = soup.find(id='main-content')
print(main_content.text)

4. Lưu dữ liệu vào file CSV
-----------------------------
import csv

data = [
    ["Tiêu đề", "Link"],
    ["Bài viết 1", "http://example.com/1"],
    ["Bài viết 2", "http://example.com/2"],
]

with open("data.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerows(data)

print("Đã lưu vào data.csv")

Gợi ý thêm:
------------
- Dùng try/except để tránh lỗi khi trang web thay đổi.
- Nếu bị chặn, thêm headers giả lập trình duyệt:
headers = {'User-Agent': 'Mozilla/5.0'}
requests.get(url, headers=headers)
