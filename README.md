# HappyDuckCoder · Portfolio

Personal portfolio and blog site for **HappyDuckCoder** (Duckilot) — AI Engineer, Full-Stack Developer, Tech Lead.

🔗 **[GitHub](https://github.com/HappyDuckCoder)**

---

## Sections

- **Hero** — Intro, portrait, Lottie animation
- **About** — Bio, tech stack (React, Node.js, Python, Computer Vision, etc.), Marquee
- **Projects** — Ceremony-style grid with featured project, cards with image fallback (Picsum)
- **Experience** — Timeline (HCMUS, OptimAI, Asoft), scroll animations, card images
- **Awards** — Top 1 AI Innovation HCMUS, Top 6 SoictAI
- **Contact** — Light theme, form, social links
- **Blog** — Under development (placeholder page)

---

## Tech Stack

- **Framework:** Next.js 15, React 19
- **Styling:** Tailwind CSS, tailwindcss-animate
- **UI / Motion:** Framer Motion, Radix UI, Lucide + React Icons
- **Other:** Lottie (client-only), TypeScript

---

## Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Install

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Build & Start

```bash
npm run build
npm start
```

### Lint

```bash
npm run lint
```
